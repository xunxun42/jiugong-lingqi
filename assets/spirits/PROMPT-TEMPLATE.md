# 立绘生成模板（本次迭代固化）

模型：智谱 `cogview-3-flash`（免费，1024×1024，图带「AI生成」水印 → 裁掉底部 120px）

## 模板

```
日系动漫风格，赛璐璐平涂，清晰黑色勾线，大眼睛，阴影单层，干净利落，
不要写实质感，不要照片质感，无文字，半身像，
{角色描述}，
深色渐变背景，居中构图，面部与肩部完整可见，穿黑色皮衣
```

## 分组约定

- **服装统一**：黑色皮衣体系（各角色只改款式细节：立领 / 露肩 / 护肩 / 兜帽）
- **构图统一**：半身、居中、面部与肩部完整
- **背景统一**：深色渐变 + 元素粒子（火光 / 冰晶 / 水泡 / 风刃 / 碎石 / 藤叶 / 星屑 / 暗影）
- **眼睛**：统一为暖色（琥珀 / 金），按元素微调
- **画风锁死**：赛璐璐平涂 + 黑色勾线 + 单层阴影，禁止写实质感

## 踩过的坑

| 问题 | 原因 | 对策 |
|---|---|---|
| 背景跑成亮色 | 模型忽略「深色」 | 强化为「背景必须是深色渐变，整体画面偏暗沉，不要白色背景，不要亮色大块背景」 |
| 男性角色跑成真人照片 | 写实倾向 | 加「动画人物五官，不要真人照片感」 |
| 表情僵硬 | 正面平视 | 用「四分之三侧脸 / 侧身回眸 / 挑眉轻笑」+ 手部动作 |
| 右下角水印 | 平台加的水印 | 统一裁掉底部 120px |

## 处理脚本

`crop(60,0,904,904)` → `resize 512×512` → `webp q88`，单张 34–72KB。
