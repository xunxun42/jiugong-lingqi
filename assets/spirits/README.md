# 精灵立绘（人型）

9 张 256×256 手写 SVG 半身立绘，文件名 = `SPIRITS` 里的 `id`。
`index.html` 通过 `art` 字段引用：

```js
art: 'assets/spirits/phoenix.svg',
```

## 设计约束

- 统一**盾形外框**，中间半身人像，保证 9 只是一套
- 实际显示尺寸只有 20–32px，所以靠**发型/头盔轮廓 + 元素配色 + 表情**区分，不堆细节
- 眼睛、眉毛、嘴都是分层画的，放大到图鉴里能看清

## 换成正式美术

导出同尺寸手绘图，**覆盖同名文件**即可，不用改代码：

- 256×256、透明底
- `svg` / `webp` / `png` 都能用（换格式记得同步改 `SPIRITS` 里的扩展名）
- 只换某一只就只覆盖那一个文件
- 加载失败会自动退回 `emoji` 字段

## 注意

- SVG 里不要放 `<script>` 或外链资源，`<img>` 加载会拦截
