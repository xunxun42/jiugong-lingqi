# 九宫灵契 · 精灵战记

**▶ 在线游玩：https://xunxun42.github.io/jiugong-lingqi/**

## 玩法

- **3×3 九宫格布阵**，双方前线相对，右列是前线（先出手，也最容易被集火）
- **先手锁定**：开战瞬间比较双方「初始总灵速」之和，高的一方先手，整场不变
- **交替出手**：先手 1 号 → 后手 1 号 → 先手 2 号 → 后手 2 号……一方出完另一方补完
- **出手排序**：每方内部按「前线 → 中军 → 后阵，每列从上到下」
- **能量大招**：普攻 +26、受击 +9，满 100 自动释放
- **元素克制**：炎 → 风 → 土 → 水 → 炎循环，光↔暗互克（克制 ×1.5 / 被克 ×0.75）
- **自动结算**：一方全灭或 20 回合后按剩余血量判定，统计伤害 / 治疗 / 承伤 / 击杀 / MVP / 星级
- **观战控制**：暂停（空格）、1x / 2x / 4x 倍速、随时撤退
- **5 关推进** + 首领战，每通关一关我方全体 +4%（灵契加成），进度本地存档

## 本地运行

直接用浏览器打开 index.html 即可，无需服务器、无需安装依赖。

## 自定义数值

index.html 底部 <script> 里三张表：

- SPIRITS —— 精灵的 HP / 攻击 / 灵速 / 大招
- STAGES —— 关卡敌方阵容与属性倍率
- PROGRESS_PER_CLEAR —— 每通关一关的成长系数
