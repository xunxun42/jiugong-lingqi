玩法

九宫灵契 · 精灵战记
  • 布阵：从下方精灵库挑 4~6 只放进左边九宫格。右列是前线，先出手、也最容易被盯上。
  • 自动出手：开战瞬间比较双方初始总灵速（存活精灵灵速之和），高的一方成为先手并整场锁定。之后每回合双方交替出手：先手 1 号 → 后手 1 号 → 先手 2 号 → 后手 2 号……一方出完则另一方补完。
  • 谁先动：每方内部按「前线 → 中军 → 后阵，每列从上到下」排序，所以前线三格最先出手。
  • 气势：上限统一 100，普攻 +50、受击 +50，攒满 自动释放大招。
  • 气势溢出：满 100 后多出的部分不清空，每 10 点让下一次大招效果 +5%（溢出 30 → +15%），释放后清零。
  • 受击优先级：先打与自己同一排的敌人，排内按 前线 → 中军 → 后阵；同排清空后从下往上（第3排 → 第2排 → 第1排）。
  • 元素克制：炎 → 风 → 土 → 水 → 炎，光 ↔ 暗互克。克制 ×1.5，被克 ×0.75。
  • 灵晶与等级：通关掉落 150 + 60×关卡 灵晶，1 灵晶 = 20 经验。角色最高 Lv 100，每级 +2% 生命与攻击（满级 ×2.98）。
  • 灵念：花 600 灵晶抽一个，9 种属性，分凡·珍·绝三档。5 颗同品质可合成 1 颗更高品质（200 + 200×品质系数）。每个角色最多装 3 个。
  • 深渊：虚魔罗 / 雷塞娅 两位首领，可重复挑战，必须在 20 回合内击杀，超时判负。首通解锁该角色。
  • 自动结算：一方全灭或打满 20 回合（普通关按剩余血量判定），自动弹出伤害 / 治疗 / 承伤 / MVP 战报。
  • 观战：战斗中可以暂停、1x / 2x / 4x 调速，也可以随时撤退重来。

开阳座 · 天光龙女

👑 王属性唤灵师觉醒型
0 / 7

故事

北斗第六星，开阳。她曾是天穹的司晨者 —— 每日第一缕天光由她点燃，自东向西铺过整片星海。千年前的那场浊潮里，她把自身的光全部抵押出去，只为让黎明的约定不断裂。此后她沉眠于星轨之下，直到听见唤灵师残存的呼声。

「我是被光燃烧殆尽的人。所以再次站起时，我要的不是被照亮，而是照亮别人。」

特殊之处

  • 唤灵点：己方王属性精灵每次成功出手 +2；王属性精灵阵亡时额外 +2。十点为满。
  • 强制插队：满槽瞬间无需等待行动轴，她直接获得最高优先级的额外回合。若已阵亡，将以 10% 最大生命复活并强行插入。
  • 唤醒：进入第二形态后，普攻与大招同时升级为 220% 倍率、同时打 2 个目标，并在每次出手后额外再出手一次。
  • 可重复：每次满槽都能再触发一次，死亡的代价也被她一并烧掉。

强度定位

她是全队唯一的越打越强型核心：前两回合是沉默的计时器，攒满十点之后变成不吃回合轴的第二个输出手。搭配天权座（+50 气势）与天玑座（嘲讽承伤）能在第 2-3 回合完成首次唤醒，此后基本上是双倍行动。

碎片获取

通关 第 6 - 10 关有几率掉落「开阳星屑」；挑战深渊 玉衡座 / 天枢座 掉落率更高。集齐 7 枚即可在此召唤。
